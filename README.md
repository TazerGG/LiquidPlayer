# Liquid Player

Player de músicas **locais** para Android (Kotlin + Jetpack Compose), offline-first.

## Sobre o Projeto

O **Liquid Player** veio como uma tentativa de recriar ver até onde eu conseguria chegar usando IA e um pouco de raiva por ter que escutar anúncio a cada 3 músicas no Spotify.
O app é **totalmente vibecoded** utilizando o **Sonnet 5.5**, tendo a linguagem **Kotlin** como sua base principal.

## Funcionalidades

- **Interface Inspirada no Spotify**
- **Reprodução Local**
- **Letras Online (Opcional)**
- **Atualizador via repo. do GitHub**

## Tecnologias Utilizadas

- **Linguagem Principal:** [Kotlin](https://kotlinlang.org/)
- **Plataforma:** Android
- **Desenvolvimento:** Vibecoding com Sonnet 5.5
